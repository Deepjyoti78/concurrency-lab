# ConcurrencyLab Architecture Documentation

ConcurrencyLab is an educational operating systems and multithreading visualization platform engineered to bridge theoretical concurrency concepts and internal CPU execution mechanics.

---

## High-Level Architecture

ConcurrencyLab is strictly partitioned into four decoupled layers:

1. **C++20 Simulation Core (`engine/`)**:
   - The authoritative source of truth for simulation state, memory values, thread queues, and synchronization invariants.
   - Built with modern C++20 using CMake and Ninja.
   - Deterministic instruction-level virtual thread execution.
   - Modular subsystems: `ThreadManager`, `IScheduler`, `SharedMemory`, `MutexManager`, `SemaphoreManager`, `RaceDetector`, `DeadlockDetector`, `ExecutionEngine`.

2. **IPC & Native Development Adapter (`server/`)**:
   - A lightweight Node.js/Express service that launches `concurrency_lab_engine.exe` via child process execution.
   - Exposes REST endpoints (`/api/scenarios`, `/api/run`, `/api/health`).
   - Translates command arguments and streams structured JSON payloads between native binary and frontend.

3. **Deterministic State & Event Layer (`frontend/src/store/`)**:
   - Zustand-driven state store managing execution progression, time-travel history, and scheduler configuration.
   - Dual-mode operation:
     - **Live Native IPC Mode**: Executes live runs on-demand through the local C++ backend.
     - **Authentic Pre-Generated Cache Mode**: Contains zero-latency complete runs of all 10 engine experiments generated directly by `concurrency_lab_engine.exe`.

4. **Interactive Visualization Layer (`frontend/src/features/`)**:
   - React 19, TypeScript, Tailwind CSS v4, Lucide icons, and SVG rendering engines.
   - Specialized interactive visualizers:
     - **Thread Execution Lanes**: Active PC pointer, registers, held mutexes, and disassembly traces.
     - **Shared Memory Subsystem**: Live value cards, delta highlights, read/write counters, and access history log.
     - **Resource Allocation Graph (RAG) & Wait-For Graph (WFG)**: Interactive SVG directed graph with Tarjan cycle highlighting for deadlocks.
     - **Dining Philosophers Round Table**: 5 philosophers, 5 forks, circular wait detection, and asymmetric order resolution.
     - **Bounded Buffer Arena**: 3-slot queue, dual semaphores (`empty_slots`, `full_slots`), mutex critical section, and invariant checks.
     - **Race Condition Diagnostic Modal**: Step-by-step interleaving breakdown of lost updates and mutual exclusion remediation.

## Directory Structure

```
concurrency-project/
├── engine/                       # C++20 Simulation Core
│   ├── include/
│   │   ├── core/                 # Thread, Program, Instruction, ExecutionEngine
│   │   ├── scheduler/            # IScheduler, RoundRobin, FIFO, Manual, SeededRandom
│   │   ├── memory/               # SharedMemory, MemoryAccessRecord
│   │   ├── synchronization/      # Mutex, MutexManager, Semaphore, SemaphoreManager
│   │   ├── detection/            # RaceDetector, DeadlockDetector
│   │   ├── events/               # ExecutionEvent, SimulationSnapshot, JsonFormatter
│   │   └── scenarios/            # IScenario, ScenarioRegistry, 10 Preconfigured Scenarios
│   ├── src/
│   │   └── main.cpp              # CLI and JSON protocol driver
│   ├── tests/
│   │   └── test_all.cpp          # 10 unit and scenario integration tests
│   └── CMakeLists.txt
├── server/                       # Node.js native IPC adapter
│   ├── src/server.ts
│   └── package.json
├── frontend/                     # React + TypeScript + Vite + Tailwind CSS
│   ├── src/
│   │   ├── components/layout/    # Header, Nav
│   │   ├── features/
│   │   │   ├── dashboard/        # Platform landing & module cards
│   │   │   ├── workspace/        # TopToolbar, Timeline, InspectorPanel, Workspace
│   │   │   ├── visualization/    # ThreadLanes, SharedMemory, RAG, DiningTable, BoundedBuffer
│   │   │   └── docs/             # Technical manual
│   │   ├── store/                # Zustand simulationStore
│   │   ├── types/                # Strict TypeScript interfaces matching C++ models
│   │   └── generated/            # engineData.json (generated by C++ engine)
│   └── vite.config.ts
├── docs/                         # Architecture, Simulation Model, Algorithms
└── README.md
```
